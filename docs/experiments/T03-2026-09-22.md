# T03：只读三方 upgrade plan（2026-09-22）

状态：in_review。该 PR 只实现 plan，不执行 apply、recover、备份、锁或任何
项目文件写入。

## 命令与输出

    gpui upgrade plan --to <template-version> --json

当前 CLI 可取得的目标是 agent-native-v1-draft。输出包含：

- schema/version、稳定 plan_id、项目名和 base/target 发行摘要；
- base_resolution：manifest、inferred_exact、manual_migration_required 或
  baseline_unavailable；
- 所有受管文件的 base/local/target hash；
- no_change、replace、keep_local、add、delete、conflict 动作和原因；
- 逻辑原子组状态、toolchain 变化、验证命令和有界 notes。

非嵌入目标版本不会假装有基线：返回 baseline_unavailable 和退出码 1。
Plan 命令没有写入项目文件。

## 三方规则

| B / L / N | 计划动作 |
| --- | --- |
| L=N | no_change |
| L=B、N 改变 | replace |
| N=B、L 改变 | keep_local |
| L=B、N 删除 | delete |
| B 不存在、N 新增且 L 不存在 | add |
| B 不存在、L/N 都存在且不同 | conflict |
| L/N 都改且都不同于 B | conflict |

## 实际证据

使用 T02 生成的 macOS+Android 项目：

    /tmp/gpui-t02-add.arbpC7/project

执行：

    gpui upgrade plan --to agent-native-v1-draft --json

结果为 status=ready、base_resolution=manifest、85 个
no_change 文件；plan_id 为：

    sha256:1dd50b4db008616ec9aae560436f701feb484a25388c257c5b0fd42773236466

在 crates/app/src/lib.rs 增加用户修改后，结果为 1 个 keep_local、
84 个 no_change，原因 target_equals_base_local_changed。原始文件没有被
写入或覆盖。

复制项目并移除 manifest、保留该用户修改后，结果为：

- status=manual_migration_required
- base_resolution=manual_migration_required
- 退出码 1
- 不生成文件操作，避免把当前用户文件伪装成 base

请求未嵌入的 future-v2 后，结果为：

- status=baseline_unavailable
- 退出码 1
- notes 明确说明目标版本不在当前 CLI 中
