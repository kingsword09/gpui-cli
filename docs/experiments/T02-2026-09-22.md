# T02：模板基线 manifest（2026-09-22）

状态：in_review。本 PR 实现新项目和 init --add 的 manifest/基线记录，
不实现 T03 的三方 plan/apply。

## 实现内容

- 新项目生成 .gpui/template-manifest.json，记录 schema、generator/template
  版本、选定平台、GPUI 依赖 revision、嵌入基线 content ID、逻辑原子组和
  每个受管理文件的 SHA-256。
- 每个文件同时记录 embedded template_path，后续升级计划可以从当前 CLI
  的固定模板重建并校验 base 内容；未知 template/content ID 返回
  baseline_unavailable。
- init --add 将新增平台文件加入 manifest，更新平台依赖组；已有文件只有在
  当前内容仍等于旧 base 时才登记新的 base。用户修改的共享文件触发冲突并且
  manifest/项目文件均不被部分写入。
- .gpui/* 继续忽略 live token/session，只有
  .gpui/template-manifest.json 可被 Git 跟踪。旧模板的 .gpui/ 规则在
  init --add 时可安全迁移。

    cargo fmt --check

新增模板测试覆盖：

- manifest 生成、文件 hash、逻辑组和嵌入 base 复取；
- macOS → Android 增平台后的 manifest group/platform 更新；
- 修改 crates/app/src/lib.rs 后拒绝覆盖且不改变原 manifest；
- 没有旧 manifest、但仍使用旧 .gitignore 时先迁移跟踪规则再生成 manifest。

实际 CLI 生成命令：

    cargo run --locked -- init t02-probe \
      --path /tmp/gpui-t02.9eJPnH/project \
      --targets macos,android \
      --title 'T02 Probe' \
      --bundle-id com.example.t02probe

该项目的 manifest 结果：

- schema_version=1
- template_version=agent-native-v1-draft
- platforms=["android","macos"]

- baseline.content_id=sha256:c4a8ccdc3b2a334a84d68dea1e483539074236a6af55362d5e5c9d5fe0619320
- vendor/gpui-pre-wgpu-0.3.5/src/shaders.wgsl 归入 android-renderer
- manifest 自身未被 .gitignore 忽略；.gpui/dev-token 和
  .gpui/live/session.json 被 .gpui/* 忽略

旧项目的多版本唯一识别、manual_migration_required 报告、三方 merge plan
以及事务 apply/recover 属于 T03/T04；本 PR 只提供可验证的当前模板 base
来源和不冒认用户修改的 manifest 更新基础。
