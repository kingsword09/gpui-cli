# T04：事务 journal/recovery 核心（2026-09-22）

状态：in_progress。本 PR 是 T04 的第一子 PR，只实现纯文件 journal、精确
backup 和 hash ownership recovery；apply、项目锁、并发重核、manifest 提交
和验证阶段将在后续 T04 PR 实现。

## 核心契约

- journal schema version 为 1，事务目录为
  .gpui/upgrade/transactions/<transaction_id>/。
- 每个文件只记录安全相对路径、old/new SHA-256、精确 backup 相对路径和
  file state；路径遍历、绝对路径、重复路径和越界 backup 会拒绝。
- recovery 只有在当前文件仍等于本事务 new hash 时才恢复 old backup，或删除
  本事务新增文件；用户在失败后修改的内容保留并标记 recovery_required。
- backup hash 重新校验；缺失/损坏 backup 不静默成功。
- journal 更新使用临时文件和 rename；恢复只操作 journal 列出的精确文件，不做
  宽泛目录删除。

## 验证

    cargo test --locked upgrade::transaction::tests

    cargo test --workspace --locked
    cargo x check-design-docs

新增纯文件测试：

1. old → new 后完整 backup 恢复，事务变为 rolled_back；
2. 用户在失败后编辑文件，恢复保留用户内容并返回 recovery_required；
3. 本事务新增文件可删除，用户替换该文件时不删除；
4. 缺少 backup 时保留当前内容并记录错误；
5. 路径遍历和重复 journal entry 被拒绝。
